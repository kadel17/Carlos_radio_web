# Rádio Carlos 5.1 BETA

Veřejná webová verze Rádia Carlos (30 stanic, DJ mixážní pult, ekvalizér, barevné motivy).

Webová adresa po zapnutí GitHub Pages: https://kadel17.github.io/Carlos_radio_web/

## Zapnutí GitHub Pages

1. Otevřete [Settings → Pages](https://github.com/kadel17/Carlos_radio_web/settings/pages).
2. V **Build and deployment** vyberte **Deploy from a branch**.
3. Nastavte větev **main** a složku **/(root)**.
4. Klikněte na **Save** a vyčkejte na dokončení nasazení.

Aplikace je samostatný soubor `index.html` bez externích souborů pro grafiku. Streamy se načítají přímo ze serverů rádií; dostupnost streamů a CORS omezení řídí jejich provozovatelé.
